# 📸 SnapClass — Multimodal AI Attendance System

> Automated classroom attendance using **face recognition + voice verification** — no roll calls, no sign-in sheets.

---

## 🧠 What is SnapClass?

SnapClass is a **biometric attendance system** built for classrooms. Instead of manually marking attendance, teachers snap a photo of the class and students verify their identity via voice — the system handles the rest.

It combines two independent AI modalities:
- 🎭 **Face Recognition** — identifies who is present in a classroom photo
- 🎙️ **Voice Verification** — confirms identity using speaker embeddings

Using both makes the system significantly harder to spoof than single-factor alternatives.

---

## ✨ Features

- 📷 **Snap-based attendance** — upload a class photo and let AI do the work
- 🔊 **Voice identity verification** — speaker recognition, not speech-to-text
- 👨‍🏫 **Teacher dashboard** — manage classes, view attendance records, generate reports
- 🎓 **Student portal** — enroll biometrics, view personal attendance history
- 🔗 **QR code class joining** — students scan a code to auto-enroll in a class
- 🗄️ **Supabase backend** — cloud database + storage, no self-hosted server needed
- 🔐 **Secure auth** — passwords hashed with `bcrypt`

## 🏗️ Architecture

```
app.py                          # Entry point & routing
└── src/
    └── screens/
        ├── home_screen.py      # Login / landing page
        ├── teacher_screen.py   # Teacher dashboard
        ├── student_screen.py   # Student view
        └── components/
            └── dialog_auto_enroll.py   # QR join-code handler
```

Routing is driven by `st.session_state['login_type']` — `"teacher"`, `"student"`, or `None` (home).

## 🛠️ Tech Stack

| Category | Library |
|---|---|
| Frontend | `streamlit` |
| Face Recognition | `face-recognition`, `dlib-bin`, `scikit-learn` |
| Voice Recognition | `resemblyzer`, `librosa` |
| Database & Storage | `supabase` |
| Authentication | `bcrypt` |
| QR Codes | `segno` |
| Utilities | `numpy`, `pandas`, `pillow` |

### Why `resemblyzer`?
Instead of speech-to-text, `resemblyzer` generates **speaker d-vector embeddings** — a compact numerical fingerprint of someone's voice. This means the system recognises *who* is speaking, regardless of *what* they say, making enrollment and verification fast and language-agnostic.

## 🚀 Getting Started

### Prerequisites

- Python 3.9+
- A [Supabase](https://supabase.com) project (free tier works)
- A webcam or image source for class photos

### Installation

```bash
# Clone the repository
git clone https://github.com/Kushagra-2112/SnapClass-Multimodal-AI-Attendance.git
cd SnapClass-Multimodal-AI-Attendance

# Install dependencies
pip install -r requirements.txt
```

> **Note:** `dlib-bin` provides pre-compiled binaries so you don't need to build dlib from source. If you run into issues on Linux, ensure `cmake` is installed.

### Configuration

Create a `.env` file or set the following environment variables:

```env
SUPABASE_URL=your_supabase_project_url
SUPABASE_KEY=your_supabase_anon_key
```

### Run

```bash
streamlit run app.py
```

The app will open at `http://localhost:8501`.

## 👤 Usage

### For Teachers
1. Sign up / log in as a **Teacher**
2. Create a class and share the generated QR code with students
3. During class, upload a photo of the room
4. SnapClass identifies present students and marks attendance automatically
5. View and export attendance records from the dashboard

### For Students
1. Sign up / log in as a **Student**
2. Scan the teacher's QR code (or use the join link) to enroll in a class
3. Complete biometric enrollment — upload a face photo and record a voice sample
4. Attendance is marked automatically when the teacher runs recognition

---

## 🗂️ Database Schema (Supabase)

Key tables you'll need to set up:

| Table | Purpose |
|---|---|
| `users` | Stores teacher and student accounts |
| `classes` | Class metadata + join codes |
| `enrollments` | Student ↔ class relationships |
| `face_encodings` | Stored face vectors per student |
| `voice_embeddings` | Stored voice d-vectors per student |
| `attendance` | Attendance records per class session |

---

## 🔒 Security Notes

- Passwords are hashed with `bcrypt` before storage — plain text passwords are never saved
- Face encodings and voice embeddings are numerical vectors, not raw media files
- QR join codes are class-scoped and can be regenerated by the teacher
